# Ohbot public study demo

This is a standalone, browser-only version of the Child study page. Each
visitor's lesson stays in their own tab. It does not call the local Python API,
collect answers, or expose the MacBook microphone, camera, or physical Ohbot.

`index.html` and `.nojekyll` are the complete deployable site. Publish only
this directory to the separate public GitHub Pages repository. The full lab
in `tutor_lab.py` remains a local application.
